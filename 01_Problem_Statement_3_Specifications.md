# Problem Statement 3 Specifications

This directory contains the participant materials for Problem Statement 3.

## Structure

- `data/`: Raw data files organized by subsystem.
  - `Door/`: The test set is one continuous unlabeled stream in `Test.csv`, not a collection of per-file test sets. See the Door info kit.
  - `ACV/`
  - `Rail_Corrugation/`
  - `SHM/`
- `03_References/`: Subsystem info kits and supporting documentation or images.
  - `Door/`
  - `ACV/`
  - `Rail_Corrugation/`
  - `SHM/`
- `04_Example_Submission/`: Illustrative sample output CSVs showing the required prediction-file format.

The example submissions are illustrative only and do not contain real predictions.
